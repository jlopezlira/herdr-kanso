### First screens guidelines

- **Kansō** Simplify information, never options. At rest a panel drops facts that repeat or say nothing now: scope lines, second lines, labels, marks and colour with no reason. Those facts come back under the pointer or keyboard. Every action and option, those the app has and those we added, stays visible and one press away. Colour stays only on what asks for you, and failures stay loud.
- **Seijaku** Measured in the browser on the six first screens: rows 103 → 76 · glyphs 35 → 19 · colours 33 → 25 · lines 150 → 88. Preview's 14 lines are the file itself, so its chrome is what halves: 2 rows to 1.
- **Kansō** One fact, one place. The folder, branch, files and lines are in the pane header, so the panels drop their scope and facts lines. Header icons, the period switch, Reply and Comment fields, Everyone's, Explain, Remove all and Prune all stay.
- **Kansō** Nothing is lost: each fact moved off the first screen says where it lives now.

### Preview guidelines

- **Seijaku** The kit header: ‹ only when it came from Files or Images, the file name as the 20 title and its folder beside it, dim (the full path under the pointer). Open with and ✕ are its icons; ✕ closes the panel, besides its tab-bar button and Esc. Code is in ink with literals in muted: colour is kept for what asks for you.
- **Yūgen** One save for every file. Save (⌘S) appears only while there is an edit, as the one solid button. Saving… holds its place, then "Saved" for 2 s. Markdown no longer autosaves here and not on another computer.
- **Kansō** One press per decision, never "Press again". A programmer's editor: ⌘S saves, ⌘Z takes back. Nothing here asks twice; what could lose text gives an Undo after instead of a question before.
- **Shizen** No Refresh icon. The file follows the disk on its own: with no edit open it shows the new text without a press.
- **Kansō** Changed on disk while edited: one line with the time and two actions, one press each. Overwrite (also ⌘S) saves your text. Reload takes the disk's text. Either one leaves "Undo" on the same line (and ⌘Z) until the next edit, so neither text is lost.
- **Shizen** The computer is gone: the edit stays, the line says so, and it saves on its own when the computer answers. No Retry to press.
- **Kokō** Over 1 MB: the first 1 MB, read only, with "Cut at 1 MB" at the end (one read).
- **Seijaku** Binary and gone say what the file is, with the action that still works.
- **Kokō** Remote calls on another computer: one read to open, one write per Save (with the text it expects on disk), one stat every 5 s in front, 30 s after three quiet stats, none hidden.

### Preview guidelines

- **Yūgen** One click on a block edits it in place: the block takes the raised slab and the kit's focus ring. A click on a link still follows it.
- **Seijaku** Clicking under the last block adds a paragraph.
- **Yūgen** Source is a context icon in the header that stays lit while on, not a pill whose tooltip explains it. Its text is the file as written.
- **Seijaku** Tables edit cell by cell. Add row, Add column and Remove row are quiet links under the table, so it is not covered in ✕ icons. Done closes it. Esc closes any block.
- **Shizen** Save follows: ⌘S or the button, never on its own.
- **Seijaku** Headings 20 and 15, body 13.5, code 11.5 on w7, so a document reads like the rest of the window.

### Preview guidelines

- **Seijaku** Pins are the one pin component (: pbx-pin, pbx-reg, pbx-ov, pbx-pnote, pbx-plist, pbx-sent). On a picture a click means nothing else, so pin mode is always on and there is no tool: a click drops a numbered pin, a drag a region, the note is typed beside it, Enter ends it. The list under the picture is the message. Send to checkout (the agent of the pane in front), or ⌘↩, then "Sent to checkout 14:07". Presses: a click, the words, ⌘↩.
- **Yūgen** The size in pixels shows under the pointer, beside the folder. The picture fits the width on canvas, radius 8.
- **Kokō** Load is the one solid button and carries the cost: Load 4.2 MB. On a bad link the press is the decision, so the size belongs on the button and not in a line above it.
- **Shizen** Loading keeps the picture's frame, breathing.
- **Seijaku** Over 20 MB says what stops it, with Open with… beside it.
- **Seijaku** Inside a note, a picture to load is one row: name, size, Load.
- **Kokō** Remote calls: one stat to learn the size. Under 2 MB the copy starts at once. Over 2 MB nothing moves until Load.
