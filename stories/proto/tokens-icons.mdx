## I1 Icons, one set

### Adding an icon

This list is the only set. If you need another icon, take it from Lucide (lucide.dev/icons, version 1.72.0, ISC license). Copy its markup unchanged, add it here with an lu- id and the meaning it carries, and only then use it. One name per meaning, never a custom icon.

### Icon guidelines

- Every icon is Lucide 1.72.0, the icon's own markup, unchanged: 24 grid, stroke 2, round caps and joins. Ids are lu- and the Lucide name.
- One name per meaning across every board: one close (lu-x), one more (lu-ellipsis), one pin, one sync, one share, one layers, one terminal.
- A plain shell is lu-terminal, the same as the Terminal row in the + menu.
- Not icons, kept: the ensō marks and spinner, the blocked mark, the Claude Code and Codex marks, Hachi's pixel art, the Dawn artwork, the kansō wordmark, the macOS window lights, the board pointer.
- Flagged: Android has no Lucide icon (proposal: the word "Android" on the button). iOS uses lu-apple, the fruit, as the app does.
