## Find in the conversation, ⌘F

### Find in the conversation guidelines

- **Fukinsei** It opens under the focused pane's header, right-aligned, 420 wide: next to what it searches, not in the middle of the window.
- **Kansō** A row shows the time only. The day is its header, so "2026-11-11 14:02" on every row goes.
- **Seijaku** Previous and Next are drawn in dim while there is nothing to move to.
- **Seijaku** Failure and empty use the state pattern where the matches start. A missing file is the BLOCK: "Can't read checkout's conversation", the path as evidence, Refresh, Explain to checkout. No matches is the EMPTY plate with the search icon, and the count slot stays empty.
- **Seijaku** A plain shell gets the terminal's own search.
- **Kokō** Remote, on devbox: one read when it opens, then one when the agent stops or you press Enter.
