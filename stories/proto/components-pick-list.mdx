## D8 Send to an agent

### Send to an agent guidelines

- **Seijaku** One shell. No scope line: the draft says where the work comes from. The "To" and "Message" labels go; the field and the box say it. Find shows once more than six agents run.
- **Kansō** Each row is the agent's name, its project as one dim word, and its ensō mark. No program icon, no branch (the branch shows on the row under the pointer), no project heads.
- **Shizen** An agent that needs you cannot take a message, so it is not offered; its home is the sidebar. "Sent. cart-ui waited on its own question and got nothing." can no longer happen.
- **Seijaku** A press on a row's project word selects every agent there that can take it. The primary names the target: Send to tests, Send to 2 in acme-shop.
- **Kansō** "Pasted into its terminal and sent with Enter, as if you typed it there." goes: a caption. Cancel goes: Esc closes.
- **Kokō** Another computer: the dim word says it ("relay · devbox"). Unreachable: the row dims, says so, and is not a target.
- **Shizen** Sending is marked at once on the target's row (the kit's pending, S21: 80% and the breathing dot); the dialog closes when hc confirms. Refused: hc's words under that row and nothing else: the terminal is gone, so no retry fixes it and no agent can act; the draft stays for another target.
- **Kansō** A primary that cannot act is not drawn: with no target or an empty message there is no Send,.
- **Kokō** Remote: no reads. One hc send per target, on that agent's computer.

## D9 Open with

### Open with guidelines

- **Seijaku** Popup on the one skeleton: title 15 semibold, the path as the scope line (the computer first when it is not this one), rows 32, the editor's name and nothing else. Number keys 1 to 9 show once the keyboard moves in the list.
- **Kansō** The hints go: "last used" (it is already first), "split" (the row under the pointer says "in a split" for a terminal editor) and "no editor" (Preview is named Preview). The "In a split" heading goes. An editor that cannot open on another computer is not drawn there, so there is no "local only".
- **Kansō** The 1px rule under the header and the "Esc" corner go.
- **Kansō** The coloured letter tiles with white letters (six hex colours) go: the name tells the editors apart.
- **Seijaku** Looking: the kit skeleton. None: one dim sentence. Failure: the probe's own words, then Refresh; no Explain (nothing an agent can do about mdfind).
- **Kokō** Remote: none. Editors are found on this computer once and cached in open-with.found; on another computer the editor opens over its own SSH.
