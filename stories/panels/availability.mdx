### No tool guidelines

- **Seijaku** A panel that needs a tool exists only where the tool does: docker for Containers, xcrun simctl or the Android SDK's adb for Simulator, macOS or Windows for Memory. Without it there is no button, no Settings row and no job.
- **Seijaku** It replaces three sentences in empty panels: "Docker is not installed on this computer.", "Memory is not available on Linux." and Simulator's install rows.
- **Seijaku** The probe runs once when the window starts and again when Settings opens, so installing Docker later brings Containers back without a restart of kansō.
- **Seijaku** On a project that lives on another computer, Containers follows that computer's docker; Simulator and Memory stay on this one.
- **Yūgen** The Simulator's rule, hidden when no tool is found, becomes the rule for all three.
