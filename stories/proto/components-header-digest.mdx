## Pane header, every digest state

### Pane header guidelines

- **Seijaku** Replaces. The same ten states and the same segments, drawn with the header spacing of pane header.
- **Kansō** The 6 px dot beside the verdict goes. The verdict is already a word in its colour: blocked for failed, conflicts and changes requested, working for running and behind, done for ready.
- **Shizen** Needs you is the blocked wash, the breathing bar and the mark.
- **Kansō** Kept: the shimmer. Simplified: the counting dots give way to the shimmer after a working name. The battery branch at:362 also drops the shimmer, against "motion never stops"; the build removes that branch too.
- **Kokō** Remote: as pane header. One gh pr view per distinct branch when an agent stops, and every 60 s only while a check is pending.
