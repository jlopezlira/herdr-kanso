## P11 Shipped

### Shipped guidelines

- **Seijaku** The kit header with the period as the scope: This week. Under it the kit segmented Day · Week · Month · Year with ‹ and ›; Share and Refresh are the header's icons.
- **Kansō** The hero is the kit metric (48): lines added, lines removed in muted, then one line for the change, in words with an arrow, in muted. A colour on it would read as an agent state.
- **Kansō** The counts are one dim line: PRs merged, commits, reviews and the streak. "Repositories" goes: By repository counts them. "Contributions" is GitHub's sum of the others, so it leads only on a Day, where line sums don't exist.
- **Seijaku** The streak is part of that line; a click on it opens the heat map. Longest streak is a record, and it is in Records.
- **Kansō** At rest the only record shown is a new one ("new", in ink). Records, When you ship and Computers are one row each, with their count or their one-word answer, and open on click. Their charts are drawn in ink (foreground at 25 to 100%), never accent.
- **Kansō** The all-time sentence ("1,204 pull requests merged … since you joined GitHub in 2014") goes. It leads nowhere, and the bests are in Records.
- **Kansō** By repository: the top 3, one line each, then Show 8 more. Commits show under the pointer; the bars go.
- **Seijaku** Every row here is the one row with a value on the right, the value at 12.5 in foreground.
- **Kokō** Remote calls: one GitHub GraphQL read per period, on open or Refresh. Line sums come from git on each computer, read once and then only what changed. No poll.

## P12 Shipped: reading, empty, signed out, share

### Shipped guidelines

- **Seijaku** First read: the kit skeleton in the hero's shape. Later reads keep the numbers and spin Refresh.
- **Kansō** Adding up: the hero says "lines so far", and the count left lives in Refresh's tooltip. The sentence "The first time takes a few minutes…" goes.
- **Seijaku** Empty: one line naming the period.
- **Seijaku** Not signed in and GitHub CLI not installed use the PR panel's words and the same actions (Sign in opens gh auth login in a pane).
- **Seijaku** GitHub not answering: the kit stale line, the last numbers at 55%.
- **Seijaku** Share is a menu, not a row of bordered buttons. Its one header line is the privacy fact (totals only), not a paragraph. A network being prepared turns dim while the image is made.
- **Kokō** The card is an image we draw ourselves (SVG to PNG), in the panel's own look: ink, no accent, the done ensō and "kansō for Herdr" at the foot.
- **Seijaku** Share is disabled until the first read lands.
