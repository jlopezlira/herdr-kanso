## S02 Title bar and tools

### Title bar and tools guidelines

- **Kansō** The title bar is the lights, 48 high, with Dawn Mode's band behind them (11). Under it the tools row, 40: + at the left; sort, search and hide at the right. Chrome buttons, 32 with 17, muted, foreground under the pointer. All four are there at rest; each says what it does in a tooltip.
- **Seijaku** + means the same in every view: a conversation in a project you pick, then New project…, Open a folder…, Add computer…. A project chosen asks which agent (S14).
- **Kokō** Sort keeps only orders. Away from its default it stays foreground and its tooltip names the order; no dot, no badge. The Show switches it repeats live in Settings · Pieces and in right-click (10).
- **Yūgen** Search opens find in place (S13), not a second list in a dialog. Hide folds the sidebar to the rail (S12).
