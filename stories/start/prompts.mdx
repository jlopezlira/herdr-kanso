# How to use the prompt for agents

Every page ends with a prompt: press **Copy prompt** and paste it with your task and the target file.

`npm run storybook` serves the MCP endpoint at `http://localhost:6006/mcp`. The published [docs manifest](https://jlopezlira.github.io/herdr-kanso/storybook/manifests/docs.json) holds every page as text.

## Prompt for agents

```text
Implement the requested component with the kit named on its page. Include every state, keep its specifications and keys, and check both themes. Reuse the existing compositions and primitives, and use kanso/tokens.json for every value.
```
