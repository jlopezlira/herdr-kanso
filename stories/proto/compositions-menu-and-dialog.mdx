## Sleep

### Sleep guidelines

- **Kansō** Sleep this agent or tab is one press, with no dialog: the moon on the focused finished pane, or the tab's menu. The tab leaves at once, a toast offers Undo for 8 s, and the row goes into Asleep breathing.
- **Shizen** Sleep a project opens a dialog only when something will not come back as it was, and says only that: "vite on web starts fresh on Wake". The tabs that keep their conversation are not listed; that is the default. When everything keeps its conversation, it sleeps at once like a tab. The primary counts: Sleep 3 tabs. Another computer is named in the title.
- **Kokō** A blocker is the row's own fact ("working" with its mark) and one blocked line. No disabled button. The dialog already re-reads every 3 s; when the agent stops, it sleeps.
- **Kansō** The Asleep dialog is removed. The sidebar's Asleep group was its second home. Every state lives on the group's rows: Going to sleep and Waking (pending: the moon breathes, the word is dim), stuck (the kit failure on the row: the step's own words, then Undo, the one action that fixes it; no Explain, no agent can act on it), asleep (Wake visible, Enter wakes), and unreachable (dimmed, no Wake). Wake all and Forget are in the row's menu.
- **Kansō** One sentence per stuck step, from sleepwork.js: "cart-ui did not exit", "cart-ui's prompt could not be cleared", "cart-ui's conversation was not found". The toast, one line tall, uses the LINE size: the same words in blocked and the same action word (Undo), no Explain; only when the group is off screen.
- **Kokō** Folded group: the count, plus "· 1 stuck" in blocked when one is. Open, no count: the rows are the count.
- **Kansō** Forget and Wake all go to the row's menu. Forget is Armed with accent, not red text.
- **Kansō** Every caption goes: "Every tab's agents exit and the tabs close…", "Put a tab you are waiting on to sleep…", "keeps its conversation" on every row.
- **Kokō** Remote: the dialog reads one session file per agent on that computer, once, then every 3 s only while blocked. Removing the Asleep dialog removes its read of every computer's store on open.

## Arrangements

### Arrangements guidelines

- **Seijaku** One shell. One list, one line per arrangement, no icon (every row had the same one). A row from another project says that project at the right. Its panes are in the row's tooltip.
- **Kansō** Overwrite and Delete show on the selected row, by state, instead of on every row. Enter opens. Delete is the kit's Armed in accent, not red text.
- **Kansō** Save shows the tab's shape (columns at their widths, each pane's program and command) instead of a text list. An agent says "new conversation": that is the fact the teaching note carried.
- **Kansō** Overwrite is not a second view. Typing a name already used turns the primary into "Overwrite web and api", which takes a second press.
- **Shizen** Opening is marked at once on its row (the kit's pending, 80% and the breathing dot) and the tab appears; nothing else changes until it is done. A refused delete puts git's or sqlite's words under that row, then Delete and Explain to checkout.
- **Kansō** Empty: "No arrangement" and the primary. The three-line caption goes.
- **Kokō** Remote: none to read; arrangements are in the local store. Opening on another computer starts each pane there (one hc call per pane).
