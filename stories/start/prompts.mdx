# How to use the prompt for agents

Open the component’s Overview and press **Copy prompt**. Paste the text with the task, the required states and the target file or surface. The prompt names the shared kit classes and token references used by that component.

Read the usage guidance and state specifications with the prompt. A copied prompt explains how to build the piece; the specifications explain what each state must show. For a larger surface, start with the composition or panel and follow its primitive dependencies.

Run `npm run storybook` to expose the local MCP endpoint at `http://localhost:6006/mcp`. The published [docs manifest](https://jlopezlira.github.io/herdr-kanso/storybook/manifests/docs.json) makes the documentation discoverable without browsing each sidebar item.

## Prompt for agents

```text
Implement the requested component with the kit identified by its page. Include the required states, preserve its specifications and keyboard behavior, and verify the result in both themes. Reuse the existing composition and primitives. Introduce no raw value where kanso/tokens.json already defines its role.
```
