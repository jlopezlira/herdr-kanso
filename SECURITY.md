# Security

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub: the repository's **Security** tab, then **Report a vulnerability**. Say what you found, how to reproduce it and which version you ran (Settings › Updates shows it).

You get an answer within a week. A fix is released first, and the report is published after it, crediting you unless you ask otherwise.

## Supported versions

The newest stable release and the newest beta get security fixes.
